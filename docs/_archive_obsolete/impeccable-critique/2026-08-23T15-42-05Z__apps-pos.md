## Verdict de spécificité

AUTHORED, prouvé dans le code : règles nommées du DESIGN.md citées dans les
commentaires, PB1 « incluse jamais ajoutée » sur 3 surfaces, offline en
personnage (succès ambre ≠ vert), comptage aveugle à la clôture. Le générique
s'infiltre : rail catégories tablette (21 cubes identiques), titres serif des
modales du kit partagé.

Scan mécanique CLI : 2 avis, tous en fichiers de test (faux positifs). Overlay
navigateur : « Walk-in » occlus 100 %, bouton tablette 4,4:1 (#968c7e sur
#2e2924), ~86 vignettes cramped-padding, tuile « SIMPLE PLATE » cyan hors
palette, transition height sur body sur les 5 routes.
